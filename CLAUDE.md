# Project Rules

## Security Rules

- Never read .env, .env.local, .env.production, or any secret file.
- Never expose API keys, tokens, certificates, or private credentials.
- Never modify deployment, CI/CD, or infrastructure files unless explicitly requested.
- Ask for confirmation before deleting files.

## Coding Rules

- Follow existing project architecture.
- Use TypeScript strict typing.
- Keep code modular and reusable.
- Do not change unrelated files.
